# E-Agriculture Irrigation System Based on Weather Forecasting

An IoT-based automatic irrigation system using ESP32 to monitor weather and soil conditions and support efficient irrigation.

## Objective

To develop a smart irrigation system that uses sensor data and weather conditions to help provide water to crops when irrigation is required.

## Technologies Used

- ESP32
- DHT11 Temperature and Humidity Sensor
- Soil Moisture Sensor
- Rain Sensor
- Relay Module
- DC/AC Motor
- IoT

## Project Overview

The system collects information from sensors such as soil moisture, temperature, humidity, and rain conditions. The ESP32 processes the sensor readings and controls the irrigation system based on the required conditions.

## Key Features

- Automatic irrigation
- Soil moisture monitoring
- Temperature and humidity monitoring
- Rain detection
- Water management
- ESP32-based control
